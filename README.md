# Power BI Superstore Sales Dashboard Project

All required assets, datasets, DAX measures, ETL scripts, and themes have been generated:

1. **`Sample_Superstore.csv`**: Full 9,994-row cleaned dataset with all 17 required columns.
2. **`superstore_theme.json`**: Official Executive Blue & Slate theme for Power BI Desktop.
3. **`DAX_Measures.dax`**: All core KPIs, Time Intelligence (YTD/PY/YoY Growth), and ranking DAX measures.
4. **`PowerQuery_ETL.m`**: Power Query M transformation code creating the complete Star Schema (`Fact_Sales`, `Dim_Date`, `Dim_Customer`, `Dim_Product`, `Dim_Geography`).
5. **Interactive Dashboard Simulator**: Available in the agent artifact directory (`superstore_dashboard_app.html`).
